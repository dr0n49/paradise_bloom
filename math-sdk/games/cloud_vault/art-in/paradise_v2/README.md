## Точные технические ограничения

Все 27 ассетов — PNG в режиме RGBA. Четыре фона полностью непрозрачны: alpha=255 у каждого пикселя. У остальных файлов есть реальные полностью прозрачные и полупрозрачные пиксели; внешние края полностью прозрачны. Шахматка есть только на QA-контакт-листах.

Окно board_frame: включительные координаты **x=71…763, y=71…720**. Эквивалентная полуинтервальная область: **[71,764) × [71,721)**. Размер **693×650**, всего **450450 пикселей**. У всех этих пикселей alpha=0. В раннем брифе размер окна был указан с ошибкой на один пиксель; здесь использована явная включительная спецификация пользователя. Техническая девятисегментная раскладка сгенерированной рамки выравнивает её проём; маска гарантирует точную прозрачность. Крыльев нет.

Три состояния лотоса имеют один холст 512×512 и общую базу. Область **[0,512) × [350,512)** у всех трёх совпадает пиксель в пиксель, включая облачную подушку и нижнее основание. Верхние лепестки меняют форму при раскрытии. У открытого лотоса светлый пустой центр без цифр и предметов. Совпадение базы проверено по байтам RGBA, хеш указан в QA JSON.

Новый арт создан встроенной **image_gen**, по одному ассету на запрос; часть запросов повторена после сетевых ошибок. Программные рисунки вместо арта не использовались. Код применён для технического изменения размера, размещения на прозрачном холсте, маски окна, совмещения общей базы и QA-листов. Фоны увеличены от исходного разрешения генерации до требуемого экспортного размера; исходные размеры и SHA-256 каждого результата записаны в `qa/qa_report.json`.

Визуально проверены отсутствие запрещённых надписей и мотивов, отдельность файлов, силуэты семи новых символов и читаемость на 64 px, три состояния лотоса, три цветка на карточке, логотип. Семантическая проверка визуальная; это не автоматическое доказательство отсутствия любого нежелательного сходства. Гранат содержит естественные округлые зёрна, а не отдельные огранённые драгоценные камни.
